# MUNI Workflows

## Customer Workflow
1. Browse homepage (views trending/recommended products).
2. Search and filter products.
3. View product details.
4. Add items to cart.
5. Proceed to checkout, selecting shipping method.
6. Pay using MTN MoMo or Airtel Money.
7. Track order status and shipment.

## Seller Workflow
1. Register as a seller.
2. Setup store profile and link bank/mobile money account.
3. List products (add descriptions, prices, images).
4. Receive order notifications.
5. Pack and hand over items for shipping.
6. Get paid once order is delivered.

## Admin Workflow
1. Login to admin dashboard.
2. Moderate new sellers and products.
3. Resolve disputes or handle refunds.
4. Manage product categories and featured items.
5. View platform analytics (GMV, users, orders).
